# NBP_Type1
Protótipo 2.5D

Decidi investir em um dos meus sonhos quando comecei a estudar jogos, que era criar um jogo com recursos que lembrassem beat-em-up e exploração, juntamente de uma estética moderna e urbana. Mas eu sentia que queria algo ousado, diferente.

Decidi então que o projeto seria uma perspectiva 2.5D.

A ideia:
> Criar a plataforma e os sistemas básicos para que um jogo pixelado pudesse atuar num jogo com profundidade.

> Criar um level design e um ambiente que relembrasse a cultura dos anos 2000, baseando costumes linguísticos, vestimentas, arquitetura e hábitos da época;

> Dar vida não só a um mundo vívido, mas à personagens caricatos;
